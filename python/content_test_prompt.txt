4. If the topic includes programming, algorithms, automation, simulation, or implementation, include code examples when useful.
5. If diagrams, schematics, workflows, or visual intuition would help, include suggested visuals or media.
6. If the content depends on factual claims, standards, research findings, historical evidence, benchmarks, or external authority, include citation needs.

1. Output valid JSON only.
